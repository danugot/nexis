# History PRD - Permissions Matrix

## 1. User Roles
* **Ordinary Member**: Level 1-3
* **Gold Member**: Level 4+

## 2. Withdrawal Rules
* **普通会员：Level 1 无提现权限；Level 2 享有 1000 元额度；Level 3 享有 2000 元额度**
* **黄金会员（Level 4+）提现上限下调至 5000，以匹配普通会员额度的收紧**
